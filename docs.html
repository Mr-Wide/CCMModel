Three phases per round. Unsettled agents step out one per port and come back with one bit: is a settled agent there? On a node with no settler the lowest-ID agent settles. The rest move through the first empty port at or after the settler's cursor; if there is none the cursor moves on, and only once every port has been tried does the group backtrack along the settler's parent port. Several start nodes are allowed, and groups that meet merge.

Also a DFS, but settled agents help. Each round the group probes the head's ports in parallel, and only then does the node's owner decide whether it can vacate; if it can, it travels on with the group as a scout for the next probe. When nobody is left unsettled, retrace walks the tree from where the group stands and drops each scout at its home the first time it gets there. Rooted starts only. Any step can hit the round limit, which ends the run there.

A DFS that builds a port-one tree: every vertex ends up with an incident tree edge carrying port 1 at one of its ends. Two things carry the O(k) bound: the search stops at the first batch that finds somewhere to go, and the traversal stops at dispersion rather than finishing the tree. Either way out, dispersion or the root being popped, is followed by retrace, which walks the scouts home along the tree. A run that hits the round limit stops without retrace.

The same DFS run agent by agent. A schedule activates agents one cycle at a time; in each, an agent reads only the agents at its node, writes its own memory and at most one other, and moves along at most one port. One agent leads: it settles the highest unsettled ID, sends the group out in probe batches, concludes each probe by rules R1 to R3c from what the group remembers, and decides the next edge and who vacates. Members carry out its numbered commands. The simulator checks every probe's conclusion against the truth. When nobody is unsettled the lead role passes to the scouts, who walk the tree home.
